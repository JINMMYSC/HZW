## 2. 2012-11-13：新勋章技能上线

来源：3533 手机世界

- 标题：`《海贼王Online》新勋章技能强悍上线`
- URL：https://www.3533.com/news/8/201211/69320/1.htm
- 页面日期：11月13日；URL 年月目录为 `201211`，因此日期为 **2012-11-13**。

正文明确新增三种勋章技能：

- `凝神聚气`
- `窒息瓦斯`
- `戒骄戒躁`

并说明：

- 普通打磨石可以打磨出上述 3 个新技能；
- `神圣打磨石A`、`神圣打磨石B`也可以选择打磨出新技能；
- `七龙珠勋章`可以通过`七海龙魂宝箱`获得。

### 恢复工程影响

装备/勋章系统至少需要支持：

```text
medal
medal_skill
polishing
polishing_material_type
sacred_polishing_stone_A
sacred_polishing_stone_B
skill_reroll_or_select
seven_dragon_ball_medal
```

宣传文没有给出三技能精确数值与 A/B 打磨石差异，因此这些仍需 JAR、攻略或录像确认。

- `海贼王之密宝传说单人纯瓦斯伤害通关龙塔副本`

- `海贼王之秘宝传说神圣打磨石打磨和镶嵌宝石`
  - 推荐卡片残片：约 189 播放、01:16；
  - BV 尚未恢复。

但要注意：

- “纯瓦斯伤害”视频中的具体技能是否就是 2012 的`窒息瓦斯`，应通过逐帧技能名称确认；

- 后期录像可以证明系统延续，不等于录像里的所有数值都等同于 2012 版本。

## 4. 龙塔年代进一步前推到 2010

QJTYW 搜索索引保留：

- `2010/3/8 23:23:00`
- 标题：`[新闻]》龙塔勋章不好《`
- URL：https://qjtyw.cn/bbs-982.html

摘要说明玩家“打了好长时间，分终于够了”并兑换龙塔勋章。

另有历史帖：

- `谁有龙塔35自动辅助`
- URL：https://qjtyw.cn/bbs-11297.html?lpage=3

因此：

- `龙塔`至少在 **2010-03-08** 已存在；
- `龙塔勋章`至少在 2010 已存在；
- 后期 Bilibili “瓦斯伤害通关龙塔副本”展示的是一个历史很早的原服系统后续形态，而不是 2024/2025 新造副本。

具体“龙塔35”的含义（35层/35级/辅助版本号）仍需正文或录像裁决，不猜。
