## 1. 2012-10-09：三个职业及战斗技能

来源：
https://www.3533.com/news/11/201210/66184/

标题：
`《海贼王OL-秘宝传说》的完全职业分析`

来源标注：当乐网；3533 页面日期：2012-10-09。

### 职业

同期文章明确写只有三个职业：

- 战士
- 格斗家
- 医师（原文简称“医”）

因此早期资料中的“发明家”继续保持 `EARLY_VERSION / VERSION_DRIFT`，不能塞入 2012 V860 时间层。

### 战士

文章明确提到：

- 战斗技：`盾击`
- 战斗技：`铁牢`
- `盾墙`
- 装备方向：敏攻
- 套装/装备名线索：`破天荒`
- 推荐副官：黄金军神
- 攻略口语中出现 `黄副`
- 副官技能简称：`咒`、`烈`

原文举例：使用盾墙后一次约 800 的伤害降为约 540。该数字只能作为玩家实测例子，不能直接外推为固定减伤公式。

### 格斗家

文章明确提到：

- `螺旋摔`：可造成眩晕
- `窝心踢`
- `回旋斩`
- `寻优`
- `寻弱`
- 强调敏捷、致命一击
- 可单人挑战“七海”
- `引怪卡`
- 推荐副官：小萌萌
- 副官技能简称：`咒`、`混`

### 医师

文章明确提到：

- `全面误诊`：群体攻击
- `全面治疗`：全队治疗
- 医师可承担群攻 + 群补
- `引怪卡` 用于集中刷怪/升级
- 推荐防装
- 推荐群咒型刀魂副官

### 对战斗模型的影响

至少需要保留：

```text
profession
combat_skill
status_stun
single_target
multi_target
party_heal
crit
agility
skill_combo
party_role
battle_item / encounter_item (引怪卡)
```

具体技能伤害公式、命中率、冷却/回合消耗仍需 JAR / 录像 / 更详细攻略确认。

## 2. 2012-11-06：神秘商店消费活动

来源：
https://www.3533.com/news/12/201211/68520/1.htm

标题：
`《海贼王OL-秘宝传说》启动欢乐消费季`

日期：2012-11-06。

正文确认游戏内存在：

- `神秘商店`
- 元宝消费统计（赠送元宝除外）
- 分档消费奖励
- 全服/分服活动排名前10奖励逻辑

奖励包名称包括：

- `元素锻造包`
- `坐骑强化包`
- `契约乐透包`
- `契约飞升包`
- `副官雷鸣包`

因此到 2012-11-06，原服至少已有：

- 元素锻造相关体系
- 坐骑强化相关体系
- 契约相关体系
- 副官礼包/强化相关体系

包名能证明体系存在，但不能仅凭包名猜测具体内部道具或概率。

## 4. 与 2012-11-26 神铸的连续演化关系

已另存：
`docs/research/ORIGINAL_DOC_2012_LATE_SYSTEMS.md`

2012-11-26 神铸文章证明：

- 80级以上金档套装可神铸
- 神铸石 + 高级元素精华
- 1–3条神铸属性
- 淬炼石刷新
- 保留强化等级、元素属性、贝壳、孔数

因此 2012-11-06 的“元素锻造包”与 11-26 的元素/神铸体系在时间上连续，但当前没有足够证据证明二者具体内容完全相同。
