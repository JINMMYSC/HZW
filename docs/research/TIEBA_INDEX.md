## 4. 当前有效搜索方法

贴吧直接帖子页经常 403，最有效流程：

1. 精确短语搜索，例如：`"出89级全身神铸+20"`；
2. 搜索引擎返回用户主页，而不是帖子本体；
3. 从用户主页恢复标题、时间、所属吧、摘要；
4. 记录用户名或匿名用户ID；
5. 再用 `用户名 + 随手互动海贼吧 + 专有词` 搜索；
6. 再用帖子标题精确反搜；
7. 搜摘要中的稀有词（副官、服务器、装备名）；
8. 如果直接贴吧域名失败，同时尝试百度的 `c.tieba.baidu.com / youhua.baidu.com / nani.baidu.com` 用户主页镜像索引。

这套方法本轮已经实际恢复到：

- 89级 / 神铸+20 / 幺蛾子 / 35服；
- 三无神技 / 35服；
- 收副官；
- 职业属性加点。

## 7. 当前结论

贴吧仍然非常有价值，但价值不在“直接把吧首页完整爬下来”，而在**搜索引擎保留下来的用户主页历史摘要**。目前已经可以稳定恢复玩家—服务器—副官—装备—系统之间的关系。长期目标仍是构建：

`用户 -> 帖子 -> 日期 -> 服务器 -> 副官/装备/系统/地图 -> 同期网页最早日期`

并用 2012–2013 原服资料不断给后期贴吧关键词做年代校准。
