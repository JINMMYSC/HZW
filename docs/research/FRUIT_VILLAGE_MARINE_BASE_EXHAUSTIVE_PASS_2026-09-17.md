## 一、果汁村主线：三测同期资料（2008-01-15）
来源：https://m.ali213.net/gonglue/080115/14346.html

### 到岛/章节入口
- 漂洋过海抵达果汁村。
- 前置“巧克力情人”：把巧克力交给胖月亮。
- 奖励：230经验、200银、3声望、30个飞行符。
- 随后“向前走，有剧情看”，剧情结束后进入“果汁村中央”。

这证明果汁村入口至少有：`抵达区域 -> NPC交付 -> 向前移动触发剧情 -> 进入中央地图` 的阶段式过图，而不是一次直接加载中央地图。

### 主线 1
青椒 -> 青椒家仓库 -> 偷菜贼 -> 5筐青椒 -> 青椒。
奖励：750经验、350银、5声望、蔬菜。

### 主线 2
进入乌索普家 -> 长鼻妇人 -> 将蔬菜放进菜篮 -> 再与妇人对话。
奖励：100经验、150银、5声望。

关键：菜篮是可交互 WorldObject，必须有任务状态前后变化。

### 主线 3
长鼻妇人 -> 进入里屋 -> 战胜小偷 -> 获得照片 -> 交回妇人。
奖励：200经验、300银、5声望。

### 主线 4
长鼻妇人给菜团子 -> 交青椒 -> 村东大屋 -> 克洛管家 -> 查询乌索普行踪。
奖励：130经验、150银、5声望。

### 主线 5
克洛 -> 大屋外南面花园 -> 偷花贼 -> 蓝玫瑰3盆 + 绿玫瑰3盆 + 黑玫瑰3盆 -> 克洛 -> 大屋最北书房 -> 梅利。
奖励：310经验、730银、5声望。

由文字可建立大屋内部方向锚点：`书房 = 大屋最北`；外部 `花园 = 大屋南面`。

### 主线 6
梅利 -> 药店购买医学书 + 航海书 -> 大屋卧室 -> 可雅。
奖励：140经验、260银、5声望。

这是果汁村“药店”直接存在的同期证据，而且药店具有任务商品购买能力。

### 主线 7
青椒 -> 村北黑森林 -> 布奇 -> 治安官 -> 大屋客厅 -> 克洛。
奖励：240经验、310银、5声望。

### 主线 8
黑森林布奇 -> 击败堵山洞门口的山姆 -> 进入山洞寻找乌索普 -> 药筐取得一包草药 -> 布奇。
奖励：300经验、400银、5声望。

关键状态：山姆是门禁型敌对 NPC；击败前后决定山洞入口可达性。药筐是 WorldObject。

### 主线 9
治安官 -> 青椒 -> 治安官。
奖励：200经验、240银、5声望。

### 主线 10
大屋可雅 -> 克洛 -> 交草药 -> 等级达到20 -> 梅利。
奖励：30个飞行卡、300经验、500银、20声望。
完成后果汁村主线结束，可向洛克岛进发。

注意：资料同时使用“飞行符”和“飞行卡”，原文保留，暂不强行归并同一道具。

### 任务链
1. 奇怪的酒保：酒保 -> 海军哨岗员战斗 -> 酒保 -> 副官登记处马克。
2. 海军考验：
   - 力量：击败亨利。
   - 智慧：马克的信 -> 酒吧加西亚。
   - 忠诚：设计图 -> 药剂师 -> 马克 -> 餐馆老板娘。
3. 愤怒的人民：老板娘 -> 监狱 -> 连续海军战斗 -> 老板 -> 老板娘 -> 索伦斯。
4. 索伦斯的烦恼：索伦斯 -> 老板娘取得帽子信物 -> 索伦斯 -> 老板娘。
5. 水落石出：老板娘 -> 海军操练场海军 -> 特效药 -> 索伦斯女儿 -> 索伦斯 -> 救索络 -> 索伦斯。
6. 不为人知的信：海军总部柜子偷信 -> 教堂莱瑞 -> 伪造信 -> 废滩区汤姆 -> 印章 -> 给伪造信盖章 -> 废滩区信使 -> 酒吧老板娘。
7. 里应外合：老板娘 -> 监狱长 -> 名单 -> 监狱老板 -> 广场海军宿舍剑圣巡逻官 -> 钥匙 -> 老板 -> 放村民 -> 剧情 -> 监狱爆炸/老板牺牲 -> 下一岛主线触发。
