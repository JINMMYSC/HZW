## 一、风车镇离岛链
现有同期资料已证明新手流程最终经过：神庙取帆 → 自动传出 → 悬崖找海特团长 → 免费获得船只 → 获得新手炮 → 装炮 → 学一级炮术 → 悬崖下方东港口 → 路飞交付“通辑/通缉手册”（原文需保留待 JAR 核字）→ 与港口下方 NPC 对话 → 出海。

恢复意义：东港口必须作为实际离岛节点；船、新手炮、炮术不是装饰奖励，而是出海前系统解锁条件。需要把 shipOwned / cannonEquipped / gunneryLevel / departureUnlocked 纳入任务状态。

## 二、风车岛 → 海军基地海域：当前能直接确认的事实
2008-01-16《海贼王海军基地主任务攻略》明确写：“你驾驶着军舰从风车岛行使到海军基地”。因此：
1. 离开风车岛后，玩家已经处于可驾驶军舰状态；
2. 风车岛与海军基地之间存在实际航行阶段，而非文字直接传送的证据；
3. 抵达/进入海军基地本身是剧情触发点。

## 三、海军基地登陆/剧情触发
同期攻略直接确认：
- 军舰从风车岛航行至海军基地；
- “进入海军基地”立即出现剧情：无耻之徒抢走药剂师的小刀和钱财；
- 玩家“向上”进入基地中心区；
- 看见酒吧并进入；
- 进入酒吧再次自动剧情：抢劫者正在抢酒保，刀客从门外进入，对话后杀死抢劫者。

这给出至少两个区域触发器：
1. MARINE_BASE_ENTRY_TRIGGER
2. BAR_INTERIOR_ENTRY_TRIGGER

并给出一个明确空间关系：入口区 -> 向上 -> 基地中心区 -> 酒吧室内。

## 四、海军基地完整任务状态链
### 1 奇怪的酒保
刀客离开 -> 与酒保谈刀客 -> 酒保装作不知道 -> 要求挑战海军哨岗员 -> 击败 -> 回酒保 -> 获得基地内幕 -> 推荐去副官登记处找马克报名参加海军。

### 2 海军的考验
副官登记处马克给三项考验：
- 力量：击败亨利。亨利在“出门向上的一副地图”。
- 智慧：马克给信 -> 交给摩根朋友加西亚；加西亚在酒吧。
- 忠诚：回马克 -> 得设计图 -> 交药剂师 -> 回马克 -> 去餐馆找老板娘。

恢复意义：任务阶段会让同一 NPC 马克连续切换 objective/dialogue/reward 状态。

### 3 愤怒的人民
老板娘说明丈夫被摩根抓去做苦力、关在监狱 -> 去监狱 -> 攻击/通过两次海军战斗 -> 见老板 -> 回老板娘 -> 被指向基地中心城索伦斯。
攻略还提示低等级玩家“带两瓶药”，说明路线战斗存在实际消耗压力。

### 4 索伦斯的烦恼
索伦斯不信任玩家 -> 回老板娘拿帽子作信物 -> 帽子交索伦斯 -> 得知索伦斯忙于为女儿报仇/处理女儿事件 -> 返回老板娘。

### 5 水落石出
老板娘 -> 海军操练场杀若干海军 -> 获得特效药 -> 给索伦斯女儿治病 -> 索伦斯答应几天内组织反抗 -> 要求救出被抓的刀客索络 -> 救出 -> 回索伦斯 -> 得知摩根经常与某人通信 -> 要求偷信并找莱瑞教父。

### 6 不为人知的信
海军总部 -> 柜子偷信 -> 发现摩根写给海贼 -> 教堂莱瑞教父 -> 伪造信 -> 缺印章 -> 废滩区杀汤姆 -> 获得印章 -> 给伪造信盖章 -> 废滩区找信使寄信 -> 返回酒吧老板娘。

恢复意义：这是完整的 WorldObject + ItemMutation 链：柜子、原信、伪造信、印章、盖章后的信、信使寄出状态均需分开。

### 7 里应外合
老板娘 -> 得知监狱中大量无罪百姓 -> 杀监狱长取得名单 -> 名单交监狱中的老板 -> 老板要求钥匙 -> 广场上海军宿舍杀剑圣巡逻官 -> 获得钥匙 -> 交老板。

原攻略括注：“出监狱左上角的房间就是放钥匙的地方”。这句话与“广场上海军宿舍杀剑圣巡逻官后得到钥匙”的具体对象/房间关系需要视觉或 JAR 再核，不强行合并。

完成后：放出全部村民 -> 剧情 -> 老板为了避免村民后患炸毁监狱并牺牲 -> 下一岛主线触发。
