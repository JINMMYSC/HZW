# 风车镇 / 新手村全细节深挖（2026-09-17）

目标：为 V860 恢复工程建立新手村可实现级 MapSpec / QuestGraph / WorldObject / UI/过图证据基线。

## 证据等级

- `CONTEMPORARY_DIRECT`：2007–2008 同游戏攻略直接记载。
- `VERSION_CONFLICT`：不同年份同游戏攻略存在数值或操作差异。
- `VISUAL_NEEDED`：文字已证实机制，但具体像素/动画仍需录像/JAR。

## 一、地图主链

2008-04-18《网游海贼王风车镇任务攻略》直接给出的空间/任务顺序：

`遗忘之船 → 路口 → 西尔 → 村西路 → 广场 → 广场上方房屋 → 广场西南商店 → 路飞 → 村长 → 后山 → 自画王 → 路飞 → 后山山洞 → 路飞 → 木匠/斧头帮区域 → 路飞 → 神庙/神帆 → 自动传出神庙 → 悬崖 → 海特团长 → 悬崖右侧任务物 → 悬崖下方东港口 → 路飞 → 港口下方人物 → 出海`

这不是推测的地名集合，而是攻略描述出的玩家实际行走链。

## 二、完整任务/事件状态链

### 1. 遗忘之船教学
- Spawn：遗忘之船。
- 与教学 NPC 对话并选择/点击“明白”。
- 2008攻略：+20 实战经验。
- 2007-11-14更早攻略索引：船下方水手对话 +10 实战经验。
- 分类：`VERSION_CONFLICT`。不能强行统一数值；V860待JAR/录像确认。
- 教学内容涉及基本游戏操作。

### 2. 离船进入路口
- 从遗忘之船离开进入“路口”。
- 首次进入立即触发剧情。
- 2008攻略：剧情结束 +50 实战经验，并升至 Lv2。
- 实现：`EnterTrigger(firstEnter && questState) -> Cutscene -> reward -> levelUpPossible`。

### 3. 西尔魔法实验
- 西尔位于路口之后的“上面”。
- 接受“魔法实验”，攻略描述只需答应即可完成。
- 奖励：20银。
- 说明原任务类型包含纯对话/选择即完成，不一定需要战斗或物品。

### 4. 村西路情书 → 雅雅
- 村西路有红色叹号 NPC。
- 接情书任务，目标雅雅。
- 雅雅位于广场。
- 交信后得到锤子。
- 奖励：10实战经验。
- 锤子不是一次性垃圾任务物，后续山洞宝藏继续使用。

### 5. 广场上方房屋 / 宝箱 / 墨水
- 广场“上面的房屋”可进入。
- 房内存在宝箱，35银。
- 房屋旁人物要求去“广场西南角的商店”购买墨水。
- 完成奖励：15实战经验 + 10银 + 短裤。
- 直接证实新手村存在：可进入建筑、可开启宝箱、功能商店、可购买任务商品、装备奖励。

### 6. 路飞剧情 I
- 找路飞触发剧情。
- 奖励：80实战经验。
- 2008正文等级数字在网页文本中损坏，保持未知，不猜。

### 7. 村长 → 航海图 → 后山自画王
- 村长要求寻找航海图。
- 去后山遇到“自画王”。
- 自画王给予航海图。
- 回村长交付：+60实战经验。

### 8. 路飞剧情 II
- 再找路飞。
- 剧情后 +100实战经验。
- 明确升到 Lv4。

### 9. 后山山洞隐藏宝藏
- 进入后山山洞。
- 宝藏位于“右上方”。
- 必须使用前面雅雅任务获得的锤子才能砸开。
- 获得：航海日记 +100银 +15实战经验。
- 实现要求：`WorldObject(Treasure/Rock)` + `RequiredItem(Hammer)` + `UseItem` + loot/reward。

### 10. 航海日记 → 路飞 → 木匠
- 路飞拿走航海日记。
- 将宝藏获得的银币交给木匠。
- 奖励：+150实战经验。

### 11. 木匠 → 斧头帮
- 木匠说明地盘被斧头帮霸占。
- 目标：取回2把斧头。
- 区域中另有2个宝箱，内容为药品。
- 击杀怪物取得任务物。
- 奖励：80实战经验 +10银 +2捆木头 +草鞋。
- 需要区分：怪物掉落任务斧头、地图宝箱药品、任务结算装备/材料。

### 12. 木头 → 路飞
- 将2捆木头交路飞。
- +200实战经验。
- 随后路飞要求去神庙取得帆。

### 13. 神庙 / 神帆 / 藏帆地点
- 去神庙寻找“神帆”（攻略原文如此，需JAR确认NPC/称谓字符串）。
- 神帆告知藏帆地点。
- 随后触发剧情。
- 剧情完成 +300实战经验。
- **系统自动把玩家传出神庙**。
- 这是新手村确认的强制剧情过图机制：`Cutscene -> ForcedTeleport`。
- 具体传出位置、动画、黑屏/淡入等：`VISUAL_NEEDED`。

### 14. 悬崖 / 海特团长 / 第一艘船
- 到悬崖找海特团长。
- 海特团长免费造船。
- 同时给予“新手炮”。
- 玩家需要把炮装备到船上。
- 然后可向船长学习“一级炮术”。
- 再去“右边”寻找任务物品。
- 完成奖励：30银 +70实战经验。
- 明确升至 Lv6。
- 这段是陆地角色系统向海战/船只系统的正式教学切换点。

### 15. 悬崖下方 → 东港口
- 空间关系直接证实：`悬崖 下方 = 东港口`。
- 路飞也在东港口，准备出海。
- 路飞给予“通辑手册”（网页原字，疑为通缉手册，保持原始字符串待JAR确认）。
- +300实战经验。
- 与港口“下面的人”交谈后即可出海。
- 风车镇主线结束。

## 六、UI / 操作机制证据

2007-11-14更早攻略索引明确：
- 2/4/6/8或方向键移动。
- 左软键或1打开个人菜单（与后续2007评测的键位描述存在版本/文案差异，需分版本）。
- 右软键或3为交友频道（同样与后续资料可能冲突）。
- 5键搜索周围人物。

2008新手任务又直接出现：
- NPC任务标记“红色叹号”。
- 教学对话中存在“明白”选择/按钮。
- 商店购买任务物。
- 宝箱开启。
- 使用锤子作用于地图对象。
- 船炮装备操作。
- 炮术学习。
- 剧情自动传送。

V860 UI恢复时，早期键位仅作 lineage 证据，不能直接覆盖V860。
