## 3. 为什么 2020–2021 视频优先级最高

这批录像距离 V860 时代虽然仍隔多年，但目前是最接近“可直接看原游戏画面”的现代公开视频来源之一，尤其：

1. 风车镇和海军基地可与 2007–2008 同期攻略逐点交叉验证；
2. `基本操作及任务` 可以裁决 V860/后期客户端键位漂移；
3. 能直接观察菜单层级、软键提示、字体、HUD、人物移动 tick、碰撞、门和地图边界；
4. 可以确认哪些画面属于真正 J2ME/旧客户端，而不是现代《热血航线》等假阳性。

但必须逐帧记录后才能把某一具体机制升级为 `ORIGINAL_IMAGE` 或 `V860_DIRECT`。

特别注意：搜索“秘宝传说”“海贼王”在抖音非常容易串到现代手游和非游戏内容，不能只看标题关键词判定。

### 快手 / 西瓜视频 / 优酷 / 腾讯视频 / AcFun

本轮以游戏全名和部分稀有专有词搜索，暂未得到可以可靠确认的 HZW 视频实体。继续采用：

`稀有专有词 -> 标题片段 -> 作者名 -> 转载/缓存 -> 原视频ID`

而不是仅搜“海贼王”。

### YouTube

当前搜索主要串到 One Piece 动画、现代游戏以及《海贼王：寻秘世界》等无关内容，尚未确认 HZW 原游戏视频。继续重点搜中文老玩家标题的转载与自动搬运。

### 微博

公开网页搜索受 robots / 登录限制影响较大，后续应从外部搜索引擎索引、用户名、标题片段和缓存反查。
