## 世界入口

- 从“小花园码头”出港。
- 海上“往下走”到蝙蝠岛。
- 等级门槛：Lv55+ 才能进入。

工程模型：

```text
小花园码头 --出港/向下航行--> 蝙蝠岛
enterRequirement: level >= 55
```

## 关键飞行 / 任务状态规则

主线二进入墓地时会触发剧情。原攻略特别说明：

> 由于剧情关系，无法直接飞到墓地，建议飞到森林，再步行至墓地。

这说明“飞行点是否可用”不仅受地图解锁控制，还会被当前任务/剧情状态临时限制。

建议状态：

```text
flightDestination.enabled = baseUnlocked && !questStateBlocksFlight
```

不能把飞行系统实现成永远可跳的静态地图列表。

## 主线任务状态机

### Q1 村长

- 地点：广场 → 村长家
- NPC：村长
- 接取后再次与村长对话即可完成
- 奖励：1545 陆战经验，556 银币

状态：`TALK -> TALK_SAME_NPC -> COMPLETE`

### Q2 神父 / 墓地怨灵

- 广场找神父
- 目标：墓地超度（击杀）10 个怨灵
- 第一次进入墓地触发剧情
- 剧情期间不能直接飞墓地；攻略建议飞森林后步行
- 击杀 10 怨灵
- 返回广场神父
- 奖励：4123 陆战经验，2858 银币

状态：

```text
ACCEPT
 -> ENTER_GRAVEYARD
 -> CUTSCENE
 -> KILL wraith x10
 -> RETURN priest
 -> COMPLETE
```

### Q3 居民 / 探险者头盔

- 神父继续给任务
- 广场西南民居访问居民
- 居民要求去岔路
- 击杀探险者并收集 10 个头盔
- 返回民居
- 奖励：4334 陆战经验，2477 银币

这里再次证明：任务中间 NPC 可以把当前 objective 从 `TALK` 转换成 `KILL+COLLECT`。

### Q4 赛勒 / 羊脑

- 医生家 NPC：赛勒医生
- 去小路
- 杀羊取得 1 个羊脑
- 重要空间提示：**羊躲在树里面**
- 回医生家交赛勒
- 奖励：3110 陆战经验，1524 银币

恢复意义：

“树”在此不只是装饰；至少影响怪物可见性/空间摆放。做地图时必须保留树冠/前景遮挡关系，不能把羊直接摆在空地。

### Q5 好消息

- 赛勒接任务
- 村长家告诉村长好消息
- 回医生家找赛勒
- 奖励：2697 陆战经验，1143 银币

状态：`doctor -> villageChief -> doctor`

### Q6 城堡 / 管家 / 托瑞多 / 血液

- 赛勒提示去城堡
- 进入城堡大厅立即触发剧情
- 剧情结束后找管家接主线六
- 去卧室找托瑞多
- 与托瑞多对话 **两次**
- 托瑞多要求击杀管家
- 返回大厅击杀管家
- 掉落/取得“忏悔书”
- 把忏悔书交托瑞多
- 托瑞多再要求把“血液”交给赛勒
- 回医生家交赛勒
- 奖励：5431 陆战经验，2524 银币

这是很强的任务状态机证据：同一个 NPC 的第二次对话才推进 objective；同一 NPC（管家）会由可对话状态切换成敌对/可战斗状态。

建议 NPC 状态：

```text
Butler:
  beforeCutscene = NPC
  quest6Accepted = NPC/TARGET
  afterTorredoTalk2 = HOSTILE
  defeated = DESPAWN/DEAD
```

并支持 `NPC -> Enemy` 动态角色转换。

### Q7 收尾

- 赛勒接任务七
- 城堡卧室告诉托瑞多消息
- 村长家告诉村长消息
- 完成
- 奖励：5229 陆战经验，2287 银币

2008-08-20 的资料明确说当时蝙蝠岛主线到此结束。

## UI / 操作恢复要求

由上述任务流程反推出至少需要捕获以下真实界面：

1. NPC 对话界面（连续对话与二次对话差异）
2. 任务接受界面
3. 任务追踪/计数（10/10 怨灵、10/10 头盔）
4. 剧情自动触发时 UI 如何隐藏/切换
5. 飞行地图中墓地在该任务阶段的不可用表现
6. 怪物掉落任务物品提示（羊脑、头盔、忏悔书）
7. NPC 从普通角色变敌对目标后的表现
8. 完成任务奖励提示：陆战经验 + 银币

以上 UI 的颜色、尺寸、字体、边框、软键文字和具体坐标仍需录像/JAR逐帧恢复。

## 一比一地图恢复的新增约束

- 墓地第一次进入区域必须有 `enterTrigger`。
- 森林与墓地必须存在合理步行连通关系，因为原攻略建议“飞森林再步行墓地”。
- 民居位于广场西南方向。
- 小路的树木必须允许羊隐藏/被遮挡。
- 城堡大厅与卧室为两个独立内部区域；大厅存在剧情 trigger 和管家，卧室存在托瑞多。
- 管家必须支持 NPC→战斗目标的状态变化。
