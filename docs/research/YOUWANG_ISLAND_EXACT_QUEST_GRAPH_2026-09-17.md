## 入口条件

- 玩家等级 >= 68。
- 从冬之岛经海路进入幽忘岛。
- 登陆点：幽忘岛东海岸。
- 起始 NPC：波特林。

这证明岛屿不是单一场景，而具有海路入口、东海岸登陆节点和等级门槛。

## 完整主线状态图（原攻略编号存在“主线名称编号”和步骤编号错位，因此保存原始步骤）

1. 东海岸波特林 -> 鲜果林。
   - 敌人：妖花 Lv70。
   - 收集：10 杖果子（原文“十杖果子”，词形待 JAR 校验）。
   - 奖励：6428 银币 + 5 声望。
   - NextHint：北面瀑布温泉找乔治。

2. 进入北面瀑布温泉。
   - EnterMap/Region 自动剧情。
   - 与乔治对话。
   - 奖励：2472 银币 + 5 声望。

3. 乔治 -> 西面采药谷。
   - 敌人：药济师 Lv70（原文如此，疑似“药剂师”，保留 RAW）。
   - 收集：10 瓶止血散。
   - 奖励：6428 银币 + 5 声望。
   - NextHint：顺山坡进入瀑布后面，从城堡内找露路博士。

4. 城堡露路博士 -> 东面厨房找哈莉。
   - 目标：让哈莉多加几道菜。

5. 厨房哈莉。
   - 获得/推进：菜谱。
   - 目标：把菜谱拿给露路博士过目。

6. 菜谱交露路博士。
   - 奖励：2472 银币 + 5 声望。
   - 博士不满意菜谱，要求将菜谱交东面餐厅秋秋准备熊掌。

7. 秋秋 -> 西面日落山。
   - 击杀/收集：10 只熊掌（原文将“熊掌”写作 Lv70 对象，究竟是熊怪还是掉落物待 JAR/录像确认）。
   - 奖励：6428 银币 + 5 声望。
   - NextHint：露路博士。

8. 露路博士 -> 城堡楼上书房。
   - 目标物：《科学》书。

9. 找到《科学》。
   - 世界物件/容器交互待确认。
   - 书内夹有照片。
   - NextHint：回露路博士。

10. 露路博士。
   - 奖励：2472 银币 + 5 声望。
   - 下一目标：幽心路找守夜人，询问实验室道路。
   - 找到守夜人对话后再次奖励：2472 银币 + 5 声望。

11. 守夜人 -> 小树林。
   - 击杀：20 幻影僵尸 Lv69。
   - 奖励：6428 银币 + 5 声望。

12. 守夜人给予“回魂液”。
   - 去小树林寻找“一颗雪树”。
   - 雪树不是普通背景：任务文字明确将其作为进入冷库的路径/触发对象。
   - 进入冷库救醒阿兴。

13. 冷库阿兴被救醒。
   - 阿兴要求回去问守夜人如何救醒阿当。

14. 守夜人。
   - 对话奖励：2472 银币 + 5 声望。
   - 下一任务：北面实验室击杀奥利亚 Lv73，取得剪刀；研究院击杀幽幽僵尸 Lv73，取得 10 件幽装。
   - 完成奖励：6428 银币 + 5 声望。

15. 守夜人 -> 幽陌路男仆主管。
   - 与男仆主管对话。
   - 再去幽幽城堡找露路博士。
   - 与露路对话后返回男仆主管。
   - 奖励：6428 银币 + 5 声望。

16. 男仆主管 -> 幽幽餐厅秋秋。
   - 目标：询问“细幽粉”。

17. 秋秋之后携回魂液前往冷库。
   - 救醒阿当。
   - 奖励：6428 银币 + 5 声望。

18. 阿当 -> 东海岸。
   - 找伙伴波特/波特林。
   - 与波特林对话。
   - 奖励：2472 银币 + 5 声望。
   - 幽忘岛主线完成。

## 关键恢复机制

### 1. 地图入口触发剧情
北面瀑布温泉明确“来到…出现剧情”。实现必须支持：
`EnterRegion -> Cutscene -> NPCInteractEnabled/QuestAdvance`。

### 2. 世界对象作为隐藏地图入口
“小树林找一颗雪树进入冷库”说明雪树可能承担入口/传送触发器，而不仅是装饰 Tile。
建议模型：
`WorldObject(snow_tree) + quest_state -> EnterMap(cold_storage)`。

### 3. 多阶段任务物品链
菜谱：哈莉 -> 露路博士 -> 秋秋；
回魂液：守夜人 -> 冷库 -> 阿兴/阿当救醒；
科学书 -> 内含照片；
剪刀 + 10幽装为并列收集条件。
任务物品必须有 acquisition/use/consume/preserve 状态，而不能只做计数器。

### 4. NPC 状态变化
阿兴、阿当存在“昏迷/救醒”状态。任务阶段推进后 NPC sprite/对话/可交互状态理论上会改变，视觉变化待录像/JAR验证。

### 5. 精确导航提示
攻略保留“北面/西面/东面/顺着山坡/瀑布后面/楼上”等方向性提示。重建地图时这些方向必须与地图布局一致，不能只保证地图之间能跳转。

### 6. 经验数据缺失不是零经验
原作者明确注明：每项任务未记录经验，可能因为本人等级已封顶。因此数据库不能把这些任务的 EXP 填 0，应标记 `EXP_UNKNOWN_DUE_LEVEL_CAP`。

## 与巨兽岛衔接

已知巨兽岛主线要求 Lv70 且完成幽忘岛主线；起点同样在幽忘岛东海岸波特林。因此幽忘岛主线最终回到东海岸不是偶然，它形成下一章节的任务接力点：

`幽忘岛主线完成 -> 东海岸波特林 -> (Lv70 gate) -> 巨兽岛之旅 -> 巨兽岛海域 -> 巨兽岛外海 -> 巨兽岛码头`
