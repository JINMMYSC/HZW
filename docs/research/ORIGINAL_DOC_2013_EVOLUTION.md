## 1. 2013-06-05 / 06-06 更新：副官技能传承

来源：
https://qjtyw.cn/bbs-9925.html?lpage=287

帖子：`你妹的 明天更新爽死了`

发布时间：2013-06-05 18:27；正文记录“6月6日更新内容”。

### 副官技能传承

更新说明确认：

- 海军基地副官登记处存在 `佣兵训练官`
- 二阶以上副官可进行技能传承
- 传承会随机替换一个未锁定技能
- 同种同等级传承卷可合成更高等级
- 等级序列：`F / E / D / C / B / A / S / SS / Z`
- A级及以上传承卷可交易
- SS、Z级有概率直接增加技能栏，且 Z 概率高于 SS
- 已有同名技能不可重复传承
- 同一副官只能学习一种复活类技能和一种自动回血类技能
- 已任命或守护副官不能传承
- 转职、转生后保留传承技能
- 使用副官技能卡会刷新未锁定新技能
- `传承盒` 可开出传承卷
- `七海龙魂宝箱` 有概率获得 C/D 级传承盒
- `龙魂碎片` 可兑换 A 级传承盒

这对服务器副官技能模型影响巨大，至少需要：

```text
deputy_tier
skill_slots
locked_slots
inherited_skills
inheritance_scroll_grade
tradeable_by_grade
slot_expansion_chance
revive_skill_group_limit
auto_heal_skill_group_limit
retain_on_job_change
retain_on_rebirth
```

概率仍未知，不能猜。

## 4. 2013-06：龙枪统帅

消费排行榜第1名奖励：`龙枪统帅契约礼包`。

礼包正文确认包括：

- 最新副官 `龙枪统帅`
- `8级贝壳兑换券` ×1
- `五彩贝（原始）` ×2

龙枪统帅介绍：

- 手持龙枪和真龙盾
- 属性成长很高（具体数值未给）
- 具有“幻影长矛手”的进化型技能

### 真龙盾刺

受到物理伤害时造成反弹伤害；正文描述计算依据为：

`自身力量 × 系数`

具体系数未知。

### 圣翼转生

- 死亡回合结束时自动复活
- 恢复一定生命值
- 一场战斗最多触发 2 次（正文措辞含“系数2次”，按文本保留，不推导其他公式）

这证明副官技能系统至少需要：

```text
on_receive_physical_damage
reflect_damage
on_death_round_end
auto_revive
revive_hp
per_battle_trigger_cap
```
