## 1. 2012-11-12：七海龙魂宝箱上线

来源：

https://www.3533.com/news/8/201211/69200/

标题：

`《海贼王Online》七海龙魂宝箱隆重上线`

页面明确确认：

- `七海龙魂宝箱` 正式上线；
- 宝箱内含新道具 `龙魂碎片`；
- 宝箱还可获得：
  - 高级宝石
  - 稀有副官
  - 稀有坐骑
- `龙魂碎片` 可兑换：
  - `神圣打磨石`
  - `七孔勋章`
- 当期活动中七海龙魂宝箱半价，售价 50 元宝。

### 结构意义

至少可建立：

```text
DRAGON_SOUL_CHEST
DRAGON_SOUL_FRAGMENT
RARE_DEPUTY_REWARD
RARE_MOUNT_REWARD
ADVANCED_GEM_REWARD
MEDAL_7_SOCKET
DIVINE_POLISH_STONE
FRAGMENT_EXCHANGE
```

具体掉率、兑换数量、宝箱奖励权重仍未知，不能猜。

## 2. 2012-11-13：新勋章技能上线

来源：

https://www.3533.com/news/8/201211/69320/1.htm

标题：

`《海贼王Online》新勋章技能强悍上线`

页面明确确认三项新勋章技能：

- `凝神聚气`
- `窒息瓦斯`
- `戒骄戒躁`

同时确认：

- 普通 `打磨石` 可以打磨出三项新技能；
- `神圣打磨石A` 和 `神圣打磨石B` 也可以选择打磨出新技能；
- `七龙珠勋章` 可以通过 `七海龙魂宝箱` 获得。

因此，以下词不能再仅当成 2024–2025 后期服内容：

- 瓦斯 / 窒息瓦斯
- 神圣打磨石
- 神圣打磨石A/B
- 七龙珠勋章
- 七海龙魂宝箱
- 勋章技能打磨

## 4. 与 2013-06-05 原服更新的连续性

来源：

https://qjtyw.cn/bbs-9925.html?lpage=287

2013-06-05 保存的 6 月 6 日更新全文再次确认：

- 七海龙魂宝箱继续存在；
- 宝箱可获得传承相关道具；
- `龙魂碎片` 可兑换 A 级传承盒；
- 神秘商店继续销售七海龙魂宝箱；
- 活动入口 NPC 为沿海集市 `金团团长`。

同篇还确认：

- 副官技能传承等级：F / E / D / C / B / A / S / SS / Z；
- 新副官 `龙枪统帅`；
- `真龙盾刺`：受到物理伤害时，反弹值与自身力量 × 系数有关；
- `圣翼转生`：死亡回合结束自动复活，一场战斗最多触发 2 次；
- 8级贝壳兑换券、五彩贝、至尊/华丽贝壳礼包；
- 20/40/60/80/100/120 级藏宝图改为可叠加道具。

这形成一条连续演化链：

```text
2012-11-12 七海龙魂宝箱 / 龙魂碎片
        ->
2012-11-13 新勋章技能 / 窒息瓦斯 / 神圣打磨石A/B
        ->
2013-06-05 七海龙魂宝箱继续存在，并接入副官技能传承体系
```
