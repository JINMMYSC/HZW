## 3. 金团交叉验证

历史原服资料记录过官方“金团”语境；2013-06-05更新还明确出现沿海集市 NPC `金团团长`。因此：

- `金团`是原服历史活动体系词；
- 2013已有明确NPC和地点；
- 2022贴吧玩家仍沿用该词；
- 不同年份规则是否相同必须分版本恢复。

## 4. 本轮新增：副官/坐骑突破

普通贴吧正文抓取受403和索引不完整影响，因此本轮采用：

`随手互动海贼吧精确短语 -> 百度索引/用户主页 -> 同游戏外部老玩家回忆 -> 历史原服资料交叉验证`

### 4.1 新副官名称线索：圣骑士

2018-12-11百度知道一条寻找“以前诺基亚里面的一款大型网游海贼王”的老玩家回答写：

`以前玩了很久 以前的圣骑士副官 飞毯等等的太多了`

同页另一回答明确指向 `92le随手互动官网`，问题语境与目标游戏高度吻合。

因此新增候选：

- `圣骑士` — 副官

证据等级：`PLAYER_MEMORY / SAME_GAME_HIGH_PROBABILITY / VERSION_UNKNOWN`

不能仅凭该回忆确定：
- 正式全名是否就是“圣骑士”；
- 首次加入版本；
- V860是否已经存在；
- 属性、技能、获取方式。

但它证明此前副官名单明显不完整，后续必须用 `圣骑士` 作为稀有词反查贴吧、QJTYW、92le、活动公告、视频和JAR字符串。

### 4.2 新坐骑名称线索：飞毯

同一老玩家回忆把 `飞毯` 与 `圣骑士副官` 并列列作昔日游戏记忆点。

新增候选：

- `飞毯` — 高概率坐骑/移动外观

证据等级：`PLAYER_MEMORY / SAME_GAME_HIGH_PROBABILITY / TYPE_NEEDS_CONFIRMATION / VERSION_UNKNOWN`

这条线索非常重要，因为V860官方页把雷象、剑齿兽称为“新坐骑”，说明V860前已有坐骑；`飞毯`目前是首个找到名字的强候选旧坐骑。

但在找到同期原服正文/JAR前，不升级为V860直接证实。
