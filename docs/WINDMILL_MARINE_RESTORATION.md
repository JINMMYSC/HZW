# V860 风车镇 + 海军基地复原范围

本分支以用户提供的原版 HZW V8.60.0 J2ME 客户端为兼容目标。

## 已有原始证据

- V860 客户端：原协议、原 `.tij/.chj` 资源、地图渲染器、NPC菜单解析器、战斗解析器。
- 风车镇主线：掌上游侠 2007-11-14《海贼王风车岛主线任务》、2008-04-18《网游海贼王风车镇任务攻略》。
- 海军基地主线：掌上游侠 2008-01-16《海贼王海军基地主任务攻略》。
- 海军基地支线：掌上游侠 2008-01-21《海贼王之海军基地支线任务》。

## 复原原则

1. 有幸存资料的 NPC、任务顺序、地点、奖励和道具名称优先按资料恢复。
2. 人物/地砖使用 V860 JAR 内的原始资源，不用现代《航海王》素材替代。
3. 玩家术语使用 HZW 实际语境：副官 / 战斗技能 / 公会；共享引擎内部 `petcmd` 等名字不作为玩家界面术语。
4. 普通走路由原客户端本地动画完成，服务器只维护权威坐标；不再每一步发 type-7 瞬移包。
5. 地图切换/纠错才允许服务器发位置同步记录。

## 无法诚实宣称逐字/逐像素一致的部分

V860 客户端本地没有保存风车镇、路飞、海军基地等完整主线对白，静态逆向也没有找到原服务端任务数据库。现有证据表明任务文本、剧情状态和大量 NPC 数据主要由旧服务端下发。因此：

- 完整任务**结构、角色、地点、奖励、流程**可以按幸存攻略复原；
- 原始逐字对白只有找到旧服务端数据库、抓包、录像或截图后才能逐句校准；
- 原地图服务器二进制尚未找到，现阶段区域拓扑按攻略重建，地砖/人物使用原 V860 素材；
- 2007 与 2008 攻略少数奖励存在版本差异，以较晚资料为主，同时保留差异记录。

这不是降低目标，而是区分“原证据复原”与“缺失资料重建”，避免把后写内容冒充原厂内容。
